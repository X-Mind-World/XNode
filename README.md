# 🌐 XNode

### Open-Source IoT Projects by XminD

**XNode** is a collection of open-source projects focused on building and exploring real-world IoT nodes and systems.

The goal of XNode is to bring together concepts from **Embedded Systems, IoT, connectivity, data processing, and data storage** through practical and reproducible projects.

The projects are developed incrementally, making **learning, experimentation, failure, problem-solving, and documenting real-world experiences** part of the process.

> **XNode is more than a collection of code — it is a journey of learning and building real-world IoT systems.**

---

## 📦 XNode Projects

### 🌤 XNode-Aero

An **ESP32-based environmental monitoring node** designed to measure temperature, humidity, and light intensity.

The project brings together technologies such as:

* ESP32
* MQTT
* EMQX
* Node-RED
* InfluxDB
* Grafana
* Docker

to build a complete IoT data pipeline.

👉 [Explore XNode-Aero](./XNode-Aero/)

## 🎯 Project Philosophy

XNode projects are not expected to be complete from day one.

Each project is an opportunity to define a real problem, explore different solutions, test them, and document what we learn along the way.

**Build. Learn. Share.**
