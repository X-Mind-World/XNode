# 🌐 XNode

### خانواده پروژه‌های متن‌باز IoT از XminD

**XNode** مجموعه‌ای از پروژه‌های متن‌باز برای ساخت و بررسی نودها و سیستم‌های IoT است.

هدف XNode این است که مفاهیم مختلف **Embedded Systems، IoT، ارتباطات، پردازش و ذخیره‌سازی داده** را در قالب پروژه‌های واقعی و قابل اجرا کنار هم قرار دهد.

این پروژه‌ها به‌صورت مرحله‌ای توسعه پیدا می‌کنند؛ بنابراین بخشی از مسیر شامل **یادگیری، آزمایش، خطا، حل مسئله و مستندسازی تجربه‌های واقعی** است.

> **XNode فقط مجموعه‌ای از کدها نیست؛ مسیری برای یادگیری و ساخت سیستم‌های واقعی IoT است.**

---

## 📦 XNode پروژه‌های

### 🌤 XNode-Aero

یک نود پایش محیطی مبتنی بر **ESP32** برای اندازه‌گیری دما، رطوبت و شدت نور.

در این پروژه از فناوری‌هایی مانند:

* ESP32
* MQTT
* EMQX
* Node-RED
* InfluxDB
* Grafana
* Docker

برای ساخت یک Pipeline کامل IoT استفاده می‌شود.

👉 [مشاهده XNode-Aero](./XNode-Aero/)

XNode برای اضافه شدن پروژه‌های بیشتر طراحی شده است.
